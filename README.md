## Sobre DrivenByCode

DrivenByCode es un espacio personal, creativo y tecnológico impulsado por Diego Silva Baeza.

En diciembre de 2023, un accidente en motocicleta provocó una lesión medular que cambió profundamente mi vida. Desde entonces, el proceso de reconstrucción ha abierto nuevas preguntas, intereses y desafíos.

La programación, la investigación, el deporte adaptado y la escritura forman parte de este camino.

DrivenByCode surge como una forma de reunir esas experiencias, documentar su evolución y construir algo que trascienda el ámbito estrictamente personal.

Aquí conviven el aprendizaje técnico y la experiencia humana; la curiosidad científica y el pensamiento crítico; los proyectos digitales y la necesidad de comprender nuestra relación con el cuerpo, la sociedad y la tecnología.

**La intención no es presentar una historia terminada, sino documentar un proceso que continúa desarrollándose.**

---

## Origen y propósito

La idea central de DrivenByCode es transformar la experiencia en conocimiento, el conocimiento en proyectos y los proyectos en nuevas posibilidades.

El proyecto se desarrolla alrededor de cuatro principios:

* **Reconstrucción:** explorar nuevas capacidades, intereses y formas de construir una vida después de una transformación radical.
* **Conocimiento:** investigar, estudiar y documentar procesos de aprendizaje.
* **Tecnología:** utilizar la programación y las herramientas digitales para crear, experimentar y resolver problemas.
* **Inclusión:** contribuir a una visión del desarrollo humano que considere la diversidad de experiencias, capacidades y realidades.

Estos principios no son compartimentos aislados. Se relacionan entre sí y evolucionan a medida que aparecen nuevas preguntas, aprendizajes y proyectos.

## Áreas de desarrollo

### 1. Tecnología y programación

La programación representa una de las principales líneas de aprendizaje y desarrollo de DrivenByCode.

Este ámbito comprende el estudio de lenguajes de programación, el desarrollo web, la arquitectura de software, las API, la documentación técnica y el uso de herramientas para construir y mantener proyectos digitales.

El objetivo es avanzar progresivamente desde los fundamentos de la programación hasta el desarrollo de soluciones más completas, documentadas y mantenibles.

### 2. Investigación y electroestimulación

DrivenByCode también documenta experiencias personales relacionadas con la electroestimulación y el entrenamiento adaptado.

Esta línea contempla el seguimiento de mediciones, la observación de cambios y el estudio de aspectos relacionados con la actividad muscular después de una lesión medular.

La intención es registrar el proceso de manera organizada y favorecer el aprendizaje a partir de la experiencia.

Las observaciones personales no sustituyen la evidencia científica ni la evaluación de profesionales de la salud.

### 3. Deporte adaptado e inclusión

El deporte constituye otra dimensión importante de este recorrido.

El paraatletismo, la adaptación al entrenamiento y los desafíos asociados a la actividad física después de una lesión medular forman parte de los temas que atraviesan el proyecto.

Esta área busca visibilizar el deporte adaptado y compartir experiencias que permitan comprender mejor sus desafíos, posibilidades y aprendizajes.

### 4. Escritura y pensamiento crítico

El blog de DrivenByCode es un espacio para explorar preguntas sobre la experiencia humana, la identidad, la tecnología y la sociedad.

Entre los temas abordados se encuentran:

* Filosofía y pensamiento crítico.
* Reconstrucción personal y cambios de identidad.
* Tecnología, privacidad y sociedad digital.
* Cultura, literatura y distopías.
* Salud emocional y experiencias relacionadas con la discapacidad.
* Reflexiones sobre la vida cotidiana y las relaciones humanas.

El propósito no es ofrecer respuestas definitivas, sino desarrollar ideas, contrastar perspectivas y abrir conversaciones.

### 5. Educación y divulgación

La documentación de experiencias, investigaciones y procesos de aprendizaje también constituye una oportunidad para compartir conocimientos.

DrivenByCode busca organizar información y experiencias de forma comprensible, diferenciando las observaciones personales de los conocimientos respaldados por fuentes y evidencia.

## Tecnología y programación

El desarrollo tecnológico de DrivenByCode forma parte de un proceso de aprendizaje y construcción progresiva.

Entre las tecnologías y herramientas consideradas dentro de este recorrido se encuentran:

| Tecnología o herramienta | Aplicación                                                          |
| ------------------------ | ------------------------------------------------------------------- |
| Python                   | Fundamentos de programación y desarrollo de aplicaciones.           |
| Django                   | Desarrollo de aplicaciones web y lógica de backend.                 |
| API REST                 | Comunicación e intercambio de información entre componentes.        |
| HTML                     | Estructura de páginas web.                                          |
| CSS                      | Presentación y diseño de interfaces.                                |
| JavaScript               | Interactividad y comportamiento en el frontend.                     |
| Git                      | Control de versiones.                                               |
| GitHub                   | Gestión de repositorios y documentación.                            |
| Linux                    | Aprendizaje del entorno de desarrollo y administración de sistemas. |

Esta lista describe el ámbito tecnológico del proyecto y su recorrido de aprendizaje. No implica que todas estas tecnologías estén implementadas actualmente en producción.

La arquitectura concreta, las dependencias y el estado de cada componente deberán documentarse según su implementación real.

### Principios de desarrollo

El trabajo técnico busca avanzar con los siguientes criterios:

* Mantener una estructura de código comprensible.
* Documentar decisiones y procesos relevantes.
* Utilizar control de versiones.
* Separar los componentes según sus responsabilidades.
* Evitar la exposición de credenciales e información sensible.
* Favorecer el aprendizaje progresivo y la mantenibilidad.
* Registrar los avances de forma coherente con el estado real del proyecto.

## Investigación y electroestimulación

Una de las líneas de trabajo documentadas en la web es la observación personal de los cambios musculares asociados a la electroestimulación.

Esta área incluye contenidos sobre:

* Experiencias de entrenamiento después de una lesión medular.
* Seguimiento de mediciones antropométricas.
* Observación de cambios musculares.
* Registro de períodos de entrenamiento y recuperación.
* Preguntas sobre la actividad muscular y la adaptación física.

El objetivo es mantener un registro organizado de la experiencia y explorar las preguntas que surgen durante el proceso.

Los resultados personales deben interpretarse dentro de su contexto y no pueden generalizarse automáticamente a otras personas.

## Filosofía

Cada proceso de aprendizaje comienza con una pregunta.

Cada proyecto implica tomar decisiones, reconocer limitaciones y volver a intentarlo.

DrivenByCode nace de una experiencia personal que transformó la manera de entender el cuerpo, el tiempo, las capacidades y el futuro.

No pretende reducir esa experiencia a una historia de superación ni presentar la reconstrucción como un camino lineal.

Busca documentar el proceso con sus preguntas, contradicciones, aprendizajes y posibilidades.

La tecnología es una herramienta. La escritura permite explorar ideas. La investigación ayuda a formular nuevas preguntas. El deporte abre otros espacios de desarrollo.

Lo que conecta estas dimensiones es la voluntad de seguir construyendo.
